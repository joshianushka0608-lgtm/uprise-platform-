## Business 2: UpRise (formerly "Corntub" / "Uprise" / "Skill Economy" / "SKILLIT")

### What It Is
A unified student skill economy platform where students can post tasks, earn money, get mentored, and build verified proof-of-work portfolios — all in one app under one profile.

**Brand:** UpRise
**Tagline:** "Your Skills. Your Proof. Your Pay."
**Domain:** cornutub.xyz
**Plan:** `plans/2026-04-27-uprise-platform.md`

### Four Modes (One Profile)
1. **Post Tasks (Learner)** — create homework/projects, set budget + deadline, receive completed work
2. **Do Tasks (Earner)** — browse tasks, apply/negotiate, complete and get paid
3. **Get Mentored** — book sessions with working professionals
4. **Be a Mentor** — create mentor profile, accept mentees, earn from sessions

### Target Users
- Students: Classes 9–12 and college
- Working professionals as mentors
- Tier 2/3 India (underserved, high mobile penetration)

### Current Stage
- Plan created (2026-04-27), no code written yet
- Focused MVP scope (~40-60 hrs), supersedes old sprawling plan

### What’s Working
- Clear demand: students need help AND want to earn
- Unified platform differentiates from LinkedIn (no proof-of-work) and Fiverr (professionals only)
- Hybrid delivery (online + physical notebook) fills a real gap
- Escrow payments solve trust problem

### What’s Broken
- No code yet
- Need to decide: student verification, commission rate, first campus

### Biggest Problems
- Building initial liquidity (enough tasks + earners in same area)
- Trust deficit without reviews/ratings history
- Student ID verification approach

### Goals
- MVP: full task marketplace + mentorship + wallet + unified profile
- First target: validate with 1 campus/cohort
- Phase 2: AI recommendations, OTP + student ID verification, full auto skill tagging
