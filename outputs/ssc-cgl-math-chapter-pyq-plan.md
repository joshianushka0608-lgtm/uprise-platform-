## Phase 1 — Foundation (Week 1–2)

### Day 1 — Simplification (BODMAS / PEDMAS)
**Why:** Easiest 2-3 marks in the entire exam. Always repeats.

**Concept Review (30 min):**
- Order: Brackets → Of → Division → Multiplication → Addition → Subtraction
- Fraction simplify: divide numerator and denominator by LCM
- Modulo, factorial basics
- Quick tricks: always check for hidden division first

**Formulas:**
```
(a+b)² = a² + 2ab + b²
(a-b)² = a² - 2ab + b²
a² - b² = (a+b)(a-b)
a³ + b³ = (a+b)(a² - ab + b²)
a³ - b³ = (a-b)(a² + ab + b²)
```

**PYQs: 50 questions** (2018–2024)
- sscadda.com → "Simplification PYQs"
- Focus: BODMAS, fraction, algebra simplify
- Target: 90%+ accuracy in under 45 sec/question

### Day 2 — Percentage
**Why:** Foundation for Profit/Loss, SI/CI, DI. Gets asked EVERY year (2-3 Qs).

**Concept Review (40 min):**
- X% = X/100
- Increase/decrease percentage formula
- Successive percentage change (big trap in PYQs)
  - Two increases of 10% = (1.1 × 1.1 - 1) × 100 = 21%
  - One increase 10%, one decrease 10% = (1.1 × 0.9 - 1) × 100 = -1% (net loss)
- Fraction to percentage conversion (1/2=50%, 1/3=33.33%, 1/4=25%, 1/5=20%, 1/6=16.67%, 1/7=14.28%, 1/8=12.5%, 1/9=11.11%, 1/11=9.09%, 1/12=8.33%)

**PYQs: 50 questions** (2018–2024)
- Focus: successive %, population/depreciation, percentage of a number
- Common trap: people forget to add base, or miscalculate successive changes

### Day 3 — Ratio & Proportion
**Why:** 1-2 Qs every year, easy marks, combines well with Percentage.

**Concept Review (30 min):**
- Ratio a:b means a/b
- Fourth proportional, third proportional
- Mean proportional
- Combine ratios: if a:b = 3:4 and b:c = 5:6 → a:c = 3×5 : 4×6 = 15:24 = 5:8
- Dividing in given ratio (sum of ratios = denominator)

**PYQs: 40 questions** (2018–2024)
- Types: find missing term, divide amount in ratio, age ratio problems

### Day 4 — Average + Number System Basics
**Why:** Average is 1-2 Qs. Number system is the base for all Math.

**Average (20 min):**
- Average = Sum of values / Number of values
- Addition of new member to group: New average = Old avg + (New - Old avg) / New count
- Removal of member: similar formula
- Weighted average shortcut

**Number System (50 min):**
- Divisibility rules (2,3,4,5,6,8,9,10,11)
- LCM × HCF = Product of two numbers
- Cyclicity of last digits (2,3,7,8 — cycle of 4)
- Remainder theorem basics

**PYQs: 60 questions** (2018–2024)
- Focus: divisibility, HCF/LCM, unit digit cycles

### Day 5 — Speed, Distance & Time
**Why:** 1-2 Qs, formula-based, scoring if you know the shortcuts.

**Concept Review (40 min):**
```
Speed = Distance / Time
Average Speed = Total Distance / Total Time
(when same distance both ways: Avg = 2ab / (a+b))
Time Ratio = 1/Speed Ratio (inverse)
Relative Speed = a + b (opposite directions) = |a - b| (same direction)
Boats & Streams: Downstream = U+V | Upstream = U-V
```

**Common question types:**
- Train-platform problems
- Circular track (same direction = relative speed difference, opposite = sum)
- Early/late in journey

## Week 2 — Money & Basic Math (April 29 – May 5)

### Day 7 — Profit & Loss + Discount
**Why:** 2-3 Qs, formula-driven, learn the trap patterns.

**Concept Review (40 min):**
```
Profit = SP - CP    Loss = CP - SP
Profit% = (Profit/CP) × 100    Loss% = (Loss/CP) × 100
SP = CP × (1 + Profit%/100)
Discount% = (Marked Price - SP)/Marked Price × 100
```

**Key tricks:**
- Two successive discounts: 20% + 30% ≠ 50%. Equivalent = (0.8 × 0.7 - 1) × 100 = -44%
- Selling at cost price but giving less weight → actual profit %
- When profit% = loss% on same CP, SP always higher → always profit

**PYQs: 50 questions** (2018–2024)

---

### Day 8 — Simple Interest + Compound Interest
**Why:** 2 Qs every year, formula-heavy, learn shortcuts.

**SI Formula:**
```
SI = (P × R × T) / 100
Amount = P + SI = P(1 + RT/100)
```

**CI Formula:**
```
Amount = P(1 + R/100)^T
```

**Shortcuts:**
- SI on SI: A × R × T / 100 (only when interest is not added)
- Time 1 year: CI - SI = P × R² / 10000
- 2 years: CI - SI = P × R × (200+R) / 10000
- When rate differs each year: calculate year by year

**PYQs: 50 questions** (2018–2024)
- Focus: different rates, time period, half-yearly/quarterly compounding

---

### Day 9 — Time & Work + Pipes & Cisterns
**Why:** 1-2 Qs, inverse proportion concept, very scoring.

**Time & Work:**
```
Work = Efficiency × Time
If A does a work in X days, B in Y days → combined = XY/(X+Y) days
If A is twice as fast as B → A:B efficiency = 2:1, time = 1:2
```

**Pipes & Cisterns:** Same formula, fill rate vs empty rate

**Work in phases:**
- A works for 3 days, then B for 4 days... calculate total time
- Alternate workers with different efficiencies

**PYQs: 40 questions** (2019–2024)

---

### Day 10 — Partnership
**Why:** 1 Qs, simple extension of Ratio + Time & Work.

**Concept:**
```
Profit share = (Capital × Time) for each partner
If times are equal → divide by capital
If capitals are equal → divide by time
```

**Types:**
- Equal time, different capital → share in ratio of capital
- Equal capital, different time → share in ratio of time
- Both different → Capital × Months → find ratio

**PYQs: 30 questions** (2019–2024)

---

### Day 11 — Mixture & Alligation
**Why:** 1-2 Qs, easy marks if you know the alligation formula.

**Alligation Formula:**
```
Mean Price = (Cheaper Quantity × Price Diff) + (Dearer Quantity × Price Diff) / Total Quantity
Or: Mean Price = (C1 × Q2 + C2 × Q1) / (Q1 + Q2)
```

**Quick trick:**
```
C1 : C2 = (D - M) : (M - C1)
Where D = Dearer price, C1 = Cheaper price, M = Mean price
```

**Types:** Pure item mixed, replacement questions, alloy questions

**PYQs: 35 questions** (2018–2024)

## Phase 2 — Geometry & Advanced (Week 3–4)

### Week 3 — Geometry + Trigonometry

**Day 13 — Geometry Part 1 (Triangles + Circles)**
**Concept Review (60 min):**

**Triangle:**
```
Area = ½ × Base × Height
Pythagorean theorem: a² + b² = c² (right triangle)
Similar triangles: areas = square of ratio of sides
Median divides triangle into equal areas
```

**Important triangles:**
- 3-4-5, 5-12-13, 7-24-25, 8-15-17, 6-8-10
- 30-60-90: sides = x, x√3, 2x
- 45-45-90: sides = x, x, x√2

**Circle:**
```
Circumference = 2πr
Area = πr²
Sector Area = (θ/360) × πr²
Arc Length = (θ/360) × 2πr
Chord distance from center: d = √(r² - c²)
```

**Key theorems:**
- Equal chords → equal angles at center
- Perpendicular from center bisects chord
- Angle subtended by arc at center = 2 × angle at circumference

**PYQs: 50 questions** (2019–2024)

---

**Day 14 — Geometry Part 2 (Quadrilateral + Polygons)**
**Concept:**
- Parallelogram: Area = Base × Height; Opposite sides equal and parallel
- Rectangle: Diagonal = √(l² + b²), Area = l × b, Perimeter = 2(l+b)
- Rhombus: Area = ½ × d1 × d2
- Trapezium: Area = ½ × (a+b) × h
- Regular polygon: Interior angle = (n-2)×180/n, each exterior = 360/n

**PYQs: 40 questions** (2019–2024)

---

**Day 15 — Trigonometry Basics**
**Why:** 2-3 Qs every year. Most students lose marks here — easy to gain advantage.

**Essential Ratios (memorize):**

| Ratio | sin | cos | tan | cosec | sec | cot |
|-------|-----|-----|-----|-------|-----|-----|
| 0°    | 0   | 1   | 0   | ∞     | 1   | ∞   |
| 30°   | ½   | √3/2 | 1/√3 | 2     | 2/√3 | √3  |
| 45°   | 1/√2 | 1/√2 | 1   | √2    | √2  | 1   |
| 60°   | √3/2 | ½   | √3  | 2/√3  | 2   | 1/√3 |
| 90°   | 1   | 0   | ∞   | 1     | ∞   | 0   |

**Key Identities:**
```
sin²θ + cos²θ = 1
1 + tan²θ = sec²θ
1 + cot²θ = cosec²θ
sinθ = 1/cosecθ,  cosθ = 1/secθ,  tanθ = 1/cotθ
tanθ = sinθ/cosθ
```

**PYQs: 50 questions** (2019–2024)
- Focus: find value of expression, simplify, find angle

**Day 16 — Height & Distance (Trigonometry Application)**
**Concept:**
```
Angle of Elevation: from observer eye to object
Angle of Depression: from object to observer (same as elevation from object)
tan(θ) = Height / Distance
```

**Types:**
- Pole/building seen from ground
- Person walking away from tower — angle changes
- Two towers/people — find distance between them

**PYQs: 30 questions** (2019–2024)

**Day 17 — Mensuration 2D**
**Key Formulas (memorize):**

```
Square: Area = a², Perimeter = 4a, Diagonal = a√2
Rectangle: Area = l×b, Perimeter = 2(l+b), Diagonal = √(l²+b²)
Triangle: Area = ½bh, Perimeter = a+b+c
Circle: Area = πr², Circumference = 2πr
Semicircle: Area = ½πr², Perimeter = πr + 2r
Sector: Area = (θ/360)πr²
Parallelogram: Area = b×h
Trapezium: Area = ½(a+b)h
```

**PYQs: 40 questions** (2019–2024)

---

**Day 18 — Mensuration 3D**
**Key Formulas:**

```
Cube: Volume = a³, TSA = 6a², LSA = 4a², Diagonal = a√3
Cuboid: Volume = l×b×h, TSA = 2(lb+bh+hl), Diagonal = √(l²+b²+h²)
Sphere: Volume = (4/3)πr³, Surface = 4πr²
Hemisphere: Volume = (2/3)πr³, CSA = 2πr², TSA = 3πr²
Cylinder: Volume = πr²h, TSA = 2πr(r+h), CSA = 2πrh
Cone: Volume = (1/3)πr²h, LSA = πrl, TSA = πr(r+l) where l = √(r²+h²)
```

**PYQs: 40 questions** (2019–2024)
- Common: given volume, find TSA. Given radius + height, find everything.

**Day 21 — Algebra (Linear + Quadratic Equations)**
**Linear Equations:**
```
ax + by = c → solve by substitution/elimination
Word problems: assign variables, form equations, solve
```

**Quadratic:**
```
ax² + bx + c = 0
Roots = (-b ± √(b²-4ac)) / 2a
Sum of roots = -b/a, Product = c/a
```

**Identities (memorize):**
```
(a+b)² = a² + 2ab + b²
(a-b)² = a² - 2ab + b²
(a+b+c)² = a² + b² + c² + 2(ab+bc+ca)
a³ + b³ = (a+b)³ - 3ab(a+b)
a³ - b³ = (a-b)³ + 3ab(a-b)
```

**PYQs: 40 questions** (2019–2024)

---

**Day 22 — Coordinate Geometry + Probability**
**Coordinate Geometry:**
```
Distance = √((x₂-x₁)² + (y₂-y₁)²)
Midpoint = ((x₁+x₂)/2, (y₁+y₂)/2)
Slope = (y₂-y₁)/(x₂-x₁)
Section formula (internal): ((m.x₂+n.x₁)/(m+n), (m.y₂+n.y₁)/(m+n))
Area of triangle = ½|x₁(y₂-y₃) + x₂(y₃-y₁) + x₃(y₁-y₂)|
```

**Probability:**
```
P(E) = Favorable outcomes / Total outcomes
P(E') = 1 - P(E)
Conditional: P(A and B) = P(A) × P(B) [independent events]
```

**PYQs: 40 questions** (2020–2024)

---

**Day 23 — Permutation + Combination**
**Permutation:**
```
nPr = n! / (n-r)!
Special: arrangement of all n items = n!
```

**Combination:**
```
nCr = n! / (r!(n-r)!)
nCr = nC(n-r)
```

**Common questions:**
- Form words from letters (repeated letters matter)
- Committee selection (order doesn't matter → combination)
- Arrangement around a circle = (n-1)! for n distinct objects

**PYQs: 30 questions** (2020–2024)
